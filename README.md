# Flipbook Offline

Flipbook Offline is a set of browser extensions that save AnyFlip and FlipHTML5 flipbooks as PDF.

Official website: https://www.flipoffline.com/

## PDF workflow

1. Install the extension for the flipbook site you use.
2. Open a supported flipbook page.
3. Click the extension icon and press Start Scan.
4. Preview the pages, pick a range, and save a PDF locally.

Free exports include a DEMO watermark. Pro removes that watermark and adds orientation, quality, split files, and custom header, footer, and watermark options. Conversion runs in the browser.
